# 多轨交付矩阵规范 (Delivery Matrix)

在完成视频/音频的转录与结构提取后，系统与 Agent 提供三个定位清晰、层级递进的产物体系：

---

## 产物对比总览

| 维度 | 产物 A：单集精读教材长文 | 产物 B：模块速查大笔记 | 产物 C：模块精读全书 (新) |
| :--- | :--- | :--- | :--- |
| **文件位置** | `output/<task>/articles/P01_xxx.md` | `output/<task>/notes/模块xx_xxx_笔记.md` | `output/<task>/textbooks/模块xx_xxx_精读全书.md` |
| **阅读场景** | 单集定向查阅、微粒度推导理解、自学跟学 | 考前速查、日常查询、XMind/Markmap 脑图构建 | 体系化通读、出版级全卷精读、跨章节演进串联 |
| **内容广度** | 单 P / 单个视频全覆盖 (完好保留不删) | 跨 P 知识元聚合、多维度结构化归纳 | 模块内所有分集长文体系化整编重构 |
| **文风语感** | 严谨书面教材风（拒绝口语碎碎念） | 9 种可选风格（精简/详细/学术/教程等，不设默认） | 出版教材风（目录导引、过渡桥梁、模块总结） |
| **代码/公式** | 完整保真展示，包含推导过程 | 视风格而定（精简风格为树状节点与签名） | 全量生产级代码示例、架构图完整保留 |
| **思考题/自测** | 包含（每集自学巩固） | 视风格而定（精简风格以树状要点速查为主） | 包含（每章自测与模块综合大串讲） |

---

## 产物 A 详细规范：单集精读教材长文 (`articles/`)

每个视频/单 P 独立生成一篇长文，目标是让读者即使不看视频也能获得完整的知识传递。在整编为模块全书后，单集文章**严格保留，严禁删除**。

### 结构模板
1. **标题与导言**：明确本集知识主题、先验知识、学习目标。
2. **核心原理与语法推导**：底层运行模型、核心概念矩阵（去除主讲人闲聊与口头禅）。
3. **典型工程案例与逐行代码**：代码范式演练、关键步骤拆解、边界情况。
4. **实践要点与延伸**：高频避坑要点、随堂自测题与解析。

---

## 产物 B 详细规范：模块速查大笔记 (`notes/`)

支持 8 种风格选择（系统不设默认风格，提醒用户自主选择）：

1. **精简 (minimal) - [SSHeRun/CS-Xmind-Note 408考研思维导图树状笔记]**：
   - 彻底摒弃大段文本，完全采用“Markdown 标题 + 多级列表（`*`）缩进”构建脑图树；
   - 核心定义采用单行引用：`    * > 定义：...`；
   - 特征与步骤采用条目化：`    * 特点: 1... 2... 3...`、`    * 步骤: 1... 2...`；
   - 零口水废话，高密度知识元，原生支持 VS Code Markmap / XMind 一键渲染脑图。
2. **详细 (detailed)**：详尽大笔记，尽可能多记录内容，还原逻辑展开、示例、推导与背景讨论。
3. **学术 (academic)**：学术报告与教材专著语调，形式化理论定义、严密证明与底层模型分析。
4. **教程 (tutorial)**：保姆级步骤拆解（Step-by-Step）、代码演练与排错避坑实战。
5. **任务导向 (task_oriented)**：目标驱动、知识点转化为实操任务、技能打钩清单 (Checklists)。
6. **商业风格 (business)**：执行摘要、商业价值与落地权衡建议。
7. **会议纪要 (meeting_minutes)**：议题速览、关键发言结论、待办分工与后续动向。
8. **生活向 (life_journal)**：个人生活感悟与思考随笔。

---

## 产物 C 详细规范：模块精读全书 (`textbooks/`)

在完成同一模块的所有单集精读文章（`articles/`）后，按模块整编为一本章节流畅、首尾贯通的【模块精读全书】（Chapter Textbook）：

1. **体系化重构，消除拼凑感**：
   - 去除各单篇重复的开篇元信息与孤立标题，统一重排为出版级章节结构：
     - `# 模块 XX：[模块名称] 精读全书`
     - `## 📖 模块全书导读与全景目录`
     - `## 第 1 章：[子章节名称]`
     - `### 1.1 [知识点]`
     - ...
     - `## 模块 XX 全景总结与技术沉淀`
2. **章节逻辑过渡桥梁 (Transition Bridges)**：
   - 在各小节切换处增加承上启下的过渡段落（“承前启后”），阐明知识演化逻辑。
3. **原单集文件独立性**：
   - 模块全书落盘于 `textbooks/` 目录下，原有 `articles/` 目录下的 79 篇单集文章完整保留供定向查阅。
