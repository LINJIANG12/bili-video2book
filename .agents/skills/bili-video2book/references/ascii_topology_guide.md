# ASCII 知识拓扑框架树与排版守则

在生成**模块速查大笔记 (`notes/`)** 时，必须在笔记开头或各模块核心章节提供标准的 ASCII 知识拓扑图，帮助用户快速建立全局心理模型。

---

## 1. ASCII 拓扑树规范

### 结构原则
- **单根或明确层级**：从模块主主题出发，向下逐级展开。
- **层级清晰**：使用标准制表符 `├──`、`└──`、`│` 表达父子与同级关系。
- **信息精炼**：每个节点后附带 1 句话核心职能或关键概念。

### 示例模板
```text
模块：高并发服务端架构
├── [1] 网络 I/O 模型
│   ├── 同步阻塞 (BIO) ────── 传统一连接一线程
│   ├── 同步非阻塞 (NIO) ──── Selector 多路复用 (epoll/kqueue)
│   └── 异步 I/O (AIO) ────── Proactor 模式 (事件驱动回调)
├── [2] 线程与并发调度
│   ├── 核心线程池 ────────── ThreadPoolExecutor 七大核心参数
│   └── 协程/虚拟线程 ────── 用户态轻量级线程切换
└── [3] 分布式一致性与缓存
    ├── 缓存读写策略 ──────── Cache Aside / Write Through
    └── 分布式锁演进 ──────── Redis Redlock vs Zookeeper 临时有序节点
```

## 2. 排版与文风纪律

### 语言风格
- **去口语化**：坚决剔除“老铁们”、“懂我意思吧”、“咱们来看一下哈”等口头禅。
- **客观书面化**：采用现代科技图书、权威教材的技术语言，语调沉稳、表述精确。

### 格式要求
1. **代码块**：必须显式标注语言标识符（如 ````python`, ````bash, ````json）。
2. **公式**：采用 LaTeX 语法包裹（行内 `$E = mc^2$`，独立段落 `$$...$$`）。
3. **高亮与强调**：
   - 核心术语首次出现加粗。
   - 警示与注意点使用引用块（`> ⚠️ **注意**：...`）。
4. **表格规范**：
   - 表头必须对齐，内容避免单单元格超过 100 字符。
   - 对比维度明确（如：特性、适用场景、劣势、时间复杂度）。
